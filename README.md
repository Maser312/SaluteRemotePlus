# RemoteSalute (iOS Remote for Sber / Salute TV)

Готовый проект виртуального пульта для телевизоров на Салют ТВ под iOS. Сборка не требует Mac и настраивается напрямую через GitHub Actions и SideStore.

## Инструкция по сборке:
1. Создайте новый репозиторий на GitHub.
2. Распакуйте содержимое этого архива и залейте файлы в корень репозитория (`git add . && git commit -m "init" && git push`).
3. Перейдите во вкладку **Actions** в репозитории на GitHub.
4. Дождитесь успешного завершения пайплайна `Build IPA for SideStore`.
5. Скачайте сформированный артефакт `RemoteSalute` (внутри него будет `RemoteSalute.ipa`).
6. Откройте файл `.ipa` в приложении **SideStore** на iPhone для подписания и установки.
