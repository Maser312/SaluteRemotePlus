# Salute Remote+

Виртуальный пульт для телевизоров на Salute TV под iOS.

Проект собирается через GitHub Actions без Mac/Xcode на стороне пользователя. Полученный IPA предназначен для установки и подписи через SideStore.

## Сборка

1. Откройте вкладку **Actions** в репозитории.
2. Запустите workflow **Build for SideStore** вручную или дождитесь автоматической сборки после push в `main`.
3. Дождитесь зелёного завершения **Build for SideStore**.
4. Откройте артефакт **SaluteRemotePlus-IPA** и скачайте `SaluteRemotePlus.ipa`.
5. Передайте IPA на iPhone и откройте его через SideStore для подписи и установки.

В сборке проверяются `Info.plist`, исполняемый файл приложения и встроенный `Spench.framework`; IPA упаковывается как стандартный `Payload/SaluteRemotePlus.app`.

## Возможности

- поиск Salute TV в локальной сети;
- подключение к телевизору по коду;
- виртуальный D-pad;
- OK, Назад, Домой и основные кнопки управления;
- передача команд через игровой канал Salute TV;
- без Text Input.
